# 👶 이지 모드

모든게 최대한 쉽고 어렵지 않게 만든 모드

---

### 바닐라와 다른 점

- 스테미너, 감속, 배터리 등 제한이 없어졌습니다
- 회사 건물이 적대적이지 않습니다
- 조금씩 체력이 회복됩니다
- 아이템 수송선이 빨리 옵니다
- 마감일이 되면 자동으로 회사로 갑니다
- 오른쪽 클릭을 계속하면 아이템 스캔을 할 수 있습니다
- 샷건과 탄환을 구매할 수 있습니다
- 할인하면 알려줍니다
- 열쇠 없이 삽으로 잠긴 문을 열 수 있습니다
- 갬블링 머신으로 판매 아이템 가치를 조정할 수 있습니다
- 양 손 아이템을 들고 제트팩을 탈 수 있습니다
- 문을 열쇠로 잠글 수 있습니다
- 미니맵이 보입니다
- 죽은 플레이어를 부활시킬 수 있습니다
- 계속 스캔 할 수 있습니다
- 각종 귀엽고 다양한 아이템이 추가 되었습니다
