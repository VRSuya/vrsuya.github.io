# ✨ 새로운 코드로 프로필 만들기

새로운 코드를 넣어서 프로필 생성

---

1. **r2modman 실행**
1. **리썰 컴퍼니 게임 선택**(Select Game)
1. Import / Update 클릭
1. **Import new profile 클릭**
1. **From code 클릭**
1. [원하는 모드](../mod-information/mod-list/) 코드 붙여넣기
1. 프로파일 이름 입력
1. Create 클릭
1. 새로 생성된 프로파일 클릭
1. Select profile 클릭
1. **Start modded 눌러서 리썰 컴퍼니 실행**
