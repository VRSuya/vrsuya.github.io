# 🔁 기존 프로필 업데이트하기

기존 프로필에 새로운 코드를 넣어서 업데이트

---

1. **r2modman 실행**
1. **리썰 컴퍼니 게임 선택**(Select Game)
1. Import / Update 클릭
1. **Update existing profile 클릭**
1. **From code 클릭**
1. [원하는 모드](../mod-information/mod-list/) 코드 붙여넣기
1. 덮어쓰기 할 프로파일 선택
1. Update profile 클릭
1. 업데이트한 프로파일 클릭
1. Select profile 클릭
1. **Start modded 눌러서 리썰 컴퍼니 실행**
