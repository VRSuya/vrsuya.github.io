# 🧰 Avatar Setting Updater

## 1️⃣ 패키지 설치

[VPM 설정 문서](./VPM_Setup)를 참고하여 해당 패키지를 프로젝트에 도입합니다.

## 2️⃣ VRSuya 아이템 Unity Packages를 임포트

## 3️⃣ 아바타에 컴포넌트 추가

### 원하는 아바타에 컴포넌트 추가

![VRSuya_AvatarSettingUpdater_01.jpg](avatarsettingupdater/VRSuya_AvatarSettingUpdater_01.jpg)

- 원하는 아바타에서 **Add Component 버튼**을 눌러서 **VRSuya Avatar Setting Updater를 추가**합니다

## 4️⃣ 옵션 선택 및 적용

### 아바타 선택, 설치를 원하는 아이템 선택 후 설치

![VRSuya_AvatarSettingUpdater_02.jpg](avatarsettingupdater/VRSuya_AvatarSettingUpdater_02.jpg)

- **적용하려는 아바타**를 선택 후, **세팅을 원하는 아이템**을 선택하고, **아바타 업데이트 버튼**을 누릅니다
