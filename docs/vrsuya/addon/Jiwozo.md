# 🪣 Jiwozo

## 1️⃣ 패키지 설치

[VPM 설정 문서](./VPM_Setup)를 참고하여 해당 패키지를 프로젝트에 도입합니다.

## 2️⃣ 메뉴에서 원하는 기능 선택

### Tools → VRSuya → Jiwozo 메뉴

![VRSuya_Jiwozo.jpg](jiwozo/VRSuya_Jiwozo.jpg)

- Missing Script 컴포넌트를 **모두 선택하려면 Select All GameObject of Missing Script** 를 선택하세요
- Missing Script 컴포넌트를 **모두 삭제하려면 Remove All Missing Script Component** 를 선택하세요
