# ✨ Create a profile with new code

:::info

Currently, the English content on this page has been translated into Papago.

:::

Create a profile by adding a new code

---

1. **Run r2modman**
1. **Select the Lethal Company game** (Select Game)
1. Click Import / Update
1. **Click Import new profile**
1. **Click From code**
1. Paste [Desired Mode](../mod-information/mod-list/) code
1. Enter Profile Name
1. Click Create
1. Click a newly created profile
1. Click Select profile
1. **Start modded to run Lethal Company**
