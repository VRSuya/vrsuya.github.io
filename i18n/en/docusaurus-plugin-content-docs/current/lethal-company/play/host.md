# 📤 How to Host

:::info

Currently, the English content on this page has been translated into Papago.

:::

After running mod patched Lethal Company **Host, invite the game to Steam Friends window**

---

1. **Run Steam** and login complete
1. **Run r2modman**
1. **Select the Lethal Company game** (Select Game)
1. **Select the desired mode profile**
1. Select Profile
1. Update all if there is a mode update (yellow box)
1. **Start modded to run Lethal Company**
1. Select Online
1. **Choose host**
1. Setting the server name and whether the server is public
1. Select save slot on the right (continue or new)
1. Start
1. Send an invitation to a friend on Steam

:::warning

Invited and **not accessible while the ship is landed on the planet**

:::
