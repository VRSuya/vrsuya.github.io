# 🔁 既存のプロファイルを更新する

:::info

現在、該当ページの日本語コンテンツはPapagoに翻訳されました。

:::

既存プロフィールに新しいコードを入れてアップデート

---

1. **r2modman実行**
1. **リーサルカンパニーゲーム選択**（Select Game）
1. Import / Update クリック
1. **Update existing profile クリック**
1. **From code クリック**
1. [お好きなモード](../mod-information/mod-list/)コードの貼り付け
1. 上書きするプロファイルの選択
1. Update profile クリック
1. 更新したプロファイルをクリック
1. Select profile クリック
1. **Start moddedを押してリーサルカンパニーを実行**
