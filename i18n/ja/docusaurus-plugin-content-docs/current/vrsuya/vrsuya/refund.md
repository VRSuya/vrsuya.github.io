# 💴 払戻政策

:::info

現在、該当ページの日本語コンテンツはPapagoに翻訳されました。

:::

### 📦 デジタル商品
当店ではデジタル商品を販売しております。 **デジタル商品の払い戻し及び交換はできません。**購入前に慎重に購入するかどうかを選択し、正確なオプションを購入するかを必ず確認してください。

### 🧒 アバター専用商品の場合
また、アバター専用商品の場合は、該当アバターでのみ使用可能な製品であるため、他のアバターおよび組み合わせケースでは使用できませんので、これによる払い戻し要請に対する回答ができません。
