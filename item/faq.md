# 자주 묻는 질문과 답변 {#faq}

## 미지원 아바타에서도 사용이 가능한가요? {#unsupported-avatar}

:::info

`AFK 3종 세트`, `오타게`, `More AFK 스마트폰` 아이템은 **오프셋을 조정하면 다른 아바타에서도 사용이 가능**합니다<br>
표정 애니메이션 계열은 해당 아바타에 맞춰서 수정이 필요할 수 있습니다

전용 아바타 아이템`모구모구 프로젝트` `아시아시 프로젝트`의 경우에는 사용이 불가능 합니다

:::

## GogoLoco와 함께 사용이 가능한가요? {#gogoloco}

:::info

GogoLoco는 전용 커스텀 애니메이터를 사용하는 애드온이며, 이와 호환을 고려하여 제작되어 있지 않습니다<br>
VRSuya의 아이템들은 기본 VRChat 애니메이터와 호환성을 고려하여 제작되어 있으므로, **GogoLoco 애니메이터의 수정 방법은 [GogoLoco](https://gogoloco.net/)의 문서를 참조하거나 GogoLoco 제작자에게 문의**하시기 바랍니다

:::

## 로코모션 아이템은 VR 모드에서도 사용이 가능한가요? {#vr-locomotion}

:::info

VR 모드에서는 로코모션을 강제로 재생이 가능하나, **데스크톱 모드처럼 제작의도에 맞춰서 로코모션을 사용하기 어렵습니다**

:::

## 제가 원하는 아바타의 지원 업데이트를 해 줄 수 있나요? {#update-avatar}

:::info

VRSuya에서는 가능한 많은 아바타를 지원을 하려고 노력하고 있습니다만, **보유하고 있지 않은 아바타나 작업량이 많은 아이템의 경우 지원 업데이트가 어려울 수 있습니다**

:::

## 어떤 아바타의 JSON 파일이 보이지 않는데 어디에 있나요? {#json}

:::info

보통 아바타에 이미 **해당 본이 존재하기 때문에 패치가 필요하지 않아서 JSON 파일이 존재하지 않습니다**<br>
따라서 아바타 패치 단계를 건너뛰고, 바로 아바타에 맞는 Prefab을 아바타에 넣어주면 세팅이 완료됩니다

모구모구 프로젝트에서 `아이리`, `에쿠`, `쿠마리`, `마누카`, `마요`, `밀피`, `미사키`, `로코나`, `셀레스티아`, `시오` 아바타가 해당이 됩니다<br>
아시아시 프로젝트에서는 `아이리` 아바타가 해당이 됩니다

:::

## 이전 버전 아바타에서도 패치를 할 수 있나요? {#old-version-avatar}

:::info

`모구모구 프로젝트`와 `아시아시 프로젝트`의 아바타는 기본적으로 아바타의 최신 버전을 기준으로 제작되어 있습니다<br>
패치의 구조 특성상 이전 버전의 아바타는 패치할 수 없으므로, **최신 버전으로 아바타로 업데이트**를 하셔야 합니다

:::

## 모델을 수정한 아바타에서는 패치가 가능한가요? {#modified-avatar}

:::info

`모구모구 프로젝트`와 `아시아시 프로젝트`의 HDiffPatcher는 수정되지 않은 기본 모델 파일만 패치가 가능합니다<br>
수정된 모델의 경우<small>(페이셜 패치 등)</small>에는 블렌더를 통해 **AvatarPatcher를 통해 패치를 한 후, AvatarRebuilder로 아바타 교체**를 하는 방식으로 진행하여야 합니다

다만, VRSuya의 모델 수정은 최대한 아바타의 원본 상태를 그대로 내보내기 및 검증을 하고 있으나, **타사의 다른 아이템의 경우 속성을 덮어쓰기를 하여 올바르게 패치가 되지 않는 케이스도 존재합니다, 이 경우에는 해당 아이템 제작자가 해결하거나 직접 문제를 해결**해야 합니다

:::

## JSON 문서는 아바타를 패치하는 데 필요한 정보를 포함하고 있지 않습니다 {#update-addon}

:::info

기존에 사용하던 블렌더 애드온 캐시 데이터가 남아 있어, 애드온을 업데이트 하더라도 기존 버전`1.0.0`으로 인식해서 생긴 현상입니다, **블렌더를 다시 껐다 켜 주시면 문제가 없어집니다**

:::

## 아바타의 손이 굳어서 움직이지 않습니다 {#fx-mask}

:::info

**FX 레이어의 애니메이터에 마스크가 적용이 되어있으면 올바르게 동작하지 않습니다**<br>
애니메이터에서 마스크를 제거하거나, VRSuya Installer가 설치되어 있는 경우 `VRSuya RemoveFXMask` 컴포넌트를 추가해 주세요

![Animator Mask](/assets/faq/unity_animator_mask.jpg)

:::

## 퍼블릭으로 업로드해서 사용이 가능한가요? {#public-upload}

:::info

원칙적으로 VRSuya의 모든 아이템은 **VRChat 아바타의 Public 상태로 게시를 할 수 없습니다**

:::

## 수익 창출이 허용된 동영상이나 방송에서 사용이 가능한가요? {#monetization}

:::info

**개인 소유 및 개인으로 활동하는 채널에서는 사용이 가능**합니다<br>
가능하다면 영상 설명이나 후반에 크레딧 표기를 하는 것을 권장합니다

MCN 소속 및 MCN의 컨텐츠로 활용되는 경우에는 개별적으로 문의 및 허가를 받아야 사용이 가능합니다<br>
이를 위반한 경우에는 VRSuya에서 영상에서 해당 사용 부분의 삭제를 요청할 수 있습니다

원 저작권자가 존재하는 아이템`INTERNET YAMERO`, `숙성!! 로리신 레퀴엠☆`, `Doodle Dance`의 경우에는 VRSuya의 저작권 가이드라인보다 원 저작권자의 가이드라인을 우선하므로 이를 확인한 후에 사용해 주시기 바랍니다

:::
