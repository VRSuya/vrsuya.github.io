# アドオン {#addon}

VRSuyaが提供する[Installer](./installer)パッケージなどのアドオンを動作させるために必要な共通ライブラリです。

### AnimatorHelper

UnityのAnimator関連で使用できる便利なメソッドをまとめたライブラリです。

### AssetUtility

Unityのアセット関連で使用できる便利なメソッドをまとめたライブラリです。

### AvatarUtility

アバター内の各種コンポーネントやアセットへ簡単にアクセスするためのライブラリです。

### DuplicateUtility

PrefabにOverrideデータが存在する場合、通常の複製ではOverride情報はコピーされません。<br>
UnityエディターでPrefabを複製した場合と同じ状態のGameObjectを生成します。

### Translator

VRSuyaの各種パッケージで使用される韓国語の原文を、英語および日本語へ翻訳するライブラリです。

### UnityUtility

Unity関連で使用できる便利なメソッドをまとめたライブラリです。
