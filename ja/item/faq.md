# よくあるご質問 {#faq}

## 未対応のアバターでも使用できますか？ {#unsupported-avatar}

:::info

`AFK 3種セット`、`ヲタ芸`、`More AFK スマートフォン`は、**オフセットを調整することで他のアバターでもご利用いただけます。**<br>
表情アニメーション系のアイテムについては、アバターに合わせて表情アニメーションの調整が必要になる場合があります。

なお、アバター専用アイテム`もぐもぐプロジェクト` `足足プロジェクト`は対応アバター以外ではご利用いただけません。

:::

## GogoLocoと併用できますか？ {#gogoloco}

:::info

GogoLocoは専用のカスタムAnimatorを使用するアドオンであり、互換性を考慮して制作されたものではありません。<br>
VRSuyaのアイテムは標準のVRChat Animatorとの互換性を前提に制作していますので、**GogoLoco用Animatorの設定方法については[GogoLoco](https://gogoloco.net/)のドキュメントをご確認いただくか、GogoLocoの制作者へお問い合わせください。**

:::

## ロコモーションアイテムはVRモードでも使用できますか？ {#vr-locomotion}

:::info

VRモードでもロコモーションを再生することは可能ですが、**デスクトップモードのように、制作意図どおりの操作・挙動で使用することはできません。**

:::

## 希望するアバターへの対応アップデートは可能ですか？ {#update-avatar}

:::info

VRSuyaでは、できる限り多くのアバターへ対応できるよう努めています。
しかし、**所有していないアバターや作業量が非常に多いアイテムについては、対応アップデートが難しい場合があります。**

:::

## 一部アバターのJSONファイルが見当たりません。どこにありますか？ {#json}

:::info

多くの場合、対象アバターには**必要なボーンが標準で含まれているため、パッチが不要であり、JSONファイルも用意されていません。**<br>
そのため、アバターパッチの工程は省略し、対応するPrefabをアバターへ配置するだけでセットアップが完了します。

対象アバターは以下のとおりです。<br>
もぐもぐプロジェクト：`愛莉`、`エク`、`クマリ`、`マヌカ`、`まよ`、`ミルフィ`、`海咲`、`ロコナ`、`セレスティア`、`しお`<br>
足足プロジェクト：`愛莉`

:::

## 旧バージョンのアバターにもパッチを適用できますか？ {#old-version-avatar}

:::info

`もぐもぐプロジェクト`および`足足プロジェクト`は、最新バージョンのアバターを基準として制作されています。<br>
パッチの構造上、旧バージョンのアバターには対応していないため、**アバターを最新バージョンへアップデートしてからご利用ください。**

:::

## 改変済みアバターでもパッチを適用できますか？ {#modified-avatar}

:::info

`もぐもぐプロジェクト`および`足足プロジェクト`のHDiffPatcherは、未改変のオリジナルモデルのみパッチを適用できます。<br>
フェイシャル改変などを行っている場合は、Blenderで**AvatarPatcherを使用してパッチを適用した後、AvatarRebuilderを使用してアバターを置き換えてください。**

なお、VRSuyaでは可能な限りオリジナルモデルの状態で検証を行っていますが、**他社製アイテムの中にはモデルデータを上書きする仕様のものがあり、正常にパッチを適用できない場合があります。<br>
その場合は、該当アイテムの制作者へお問い合わせいただくか、ご自身で問題を解決していただく必要があります。**

:::

## 「このJSONファイルはアバターのパッチのための必要情報を含めていません。」と表示されます {#update-addon}

:::info

以前使用していたBlenderアドオンのキャッシュが残っているため、アドオンを更新しても旧バージョン`1.0.0`として認識されることで発生する現象です。<br>
**Blenderを再起動すると解消されます。**

:::

## アバターの手が動かなくなってしまいます {#fx-mask}

:::info

**FXレイヤーのAnimatorにAvatar Maskが設定されている場合、正常に動作しません。**<br>
AnimatorからAvatar Maskを削除するか、VRSuya Installerを導入している場合は、`VRSuya RemoveFXMask`コンポーネントを追加してください。

![Animator Mask](/assets/faq/unity_animator_mask.jpg)

:::

## Publicアバターとしてアップロードできますか？ {#public-upload}

:::info

VRSuyaのすべてのアイテムは、**VRChatのPublicアバターでの使用を禁止しています。**

:::

## 収益化された動画や配信で使用できますか？ {#monetization}

:::info

**個人で所有・運営しているチャンネルであれば、ご利用いただけます。**<br>
可能であれば、動画説明欄やエンドクレジットなどでVRSuyaのクレジット表記をお願いいたします。

MCNに所属するチャンネル、またはMCNが管理・運営するコンテンツで利用する場合は、事前のお問い合わせおよび許可が必要です。<br>
これらに違反した場合、VRSuyaより該当箇所の削除をお願いする場合があります。

また、原著作権者が存在するアイテム`INTERNET YAMERO`、`粛聖!! ロリ神レクイエム☆`、`Doodle Dance`については、VRSuyaのガイドラインよりも原著作権者の利用規約・ガイドラインが優先されます。<br>
ご利用の際は、必ず原著作権者のガイドラインをご確認ください。

:::
