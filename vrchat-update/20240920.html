개발자 업데이트 2024.9.19

2024년 9월 20일
Chatbox 2.0 및 PhysBone 떨림 완화

VRChat 아바타 제작자 프로그램 설문조사​

  • 크리에이터 경제와 연계하여 사용될 아바타 제작자들의 제작/판매 경험을 VRChat에서 수렴하고자 설문조사를 실시 중
  • 추후에 VRChat과 연계하여 아바타 판매할 사람 구하는 목적도 겸하는 듯
  • https://www.surveymonkey.com/r/2DMZ8FP

VRChat 서버 이미지 다이렉트 링크 금지​

  • 외부 웹사이트에서 VRChat 서버에서 바로 이미지 가져와서 보여주거나 링크하는 행위 금지
  • 자체 서버에 저장해서 보여주는 형태로 변경 필요
  • VRChat 월드 소개 사이트, 아바타 정보 표시 등등, 트래픽 비용은 VRChat이 내고 써드파티 사이트는 유지비가 거의 안 들기에 이러한 결정이 나온 듯
  • 10월 초에 적용 예정

Persistent User Data 오픈 베타 임박​

  • 플레이어의 진행사항, 세팅값 등, 월드마다 개개인 데이터를 서버에 저장할 수 있는 기능 곧 오픈 베타 예정

PhysBone과 Constraint 실행 순서 조정​

  • Constraint 아래에 PhysBone이 있으면 의도치 않게 떨리는 경우가 있는데, 필요한 경우 PhysBone 계산을 뒤에 하여 그런 현상을 제거
  • 예시로 아바타에 월드 고정한 물체가 있을 때, 플레이어가 움직이면 고정된 물체인데도 피직스본이 움직이는 현상을 방지
  • 단, 제약 아래에 피직스본이 있고, 또 제약이 있는 등 중첩되면 해결이 어려움
  • Contact는 아직 기술 부족으로 이와 같은 문제 해결이 어려움
  • 1인칭에서는 안 보이지만, 거울이나 다른 사람에게 보여주는 기술은 호환성 보장이 안 되므로 HeadChop으로 변경 요망

Chatbox 2.0 오픈 베타​

  • 기본값이 모든 사람들이 자신의 채팅창을 볼 수 있게 변경 (기존에는 친구 였음)
  • 해당 플레이어를 선택해서 채팅창만 끄고 켜는 기능
  • 채팅 입력 중인 내용은 보내지 않아도 다른 사람들에게 보임 (세팅창에서 변경 가능)
  • 어떤 플레이어의 채팅창이 사라지지 않게 하려면 해당 플레이어를 선택한 상태로 두면 됨
  • 모바일에도 채팅 UI 추가 및 세로 모드에서 채팅 입력이 가능하게 변경
  • 채팅창도 귀마개 모드를 하면 바깥의 플레이어의 채팅창은 안 보임
  • 필터링 기능으로 기본적인 욕설 같은 내용이 검열됨 (세팅창에서 변경 가능)
  • PC에서는 채팅 입력란에 키보드 UI 같은게 필요 없으니 기본적으로 숨겨진 상태로
  • 채팅도 신고 가능하게 변경

Example Central 출시 예정​

  • 월드 제작할 때 자주 쓰이는 기능을 빌트인해서 빠르게 월드 구축을 도와주는 시스템
  • 월드 세팅, 리더보드, 방문자 알림 등등 자주 쓰는 기능의 템플릿을 제공하는 듯
