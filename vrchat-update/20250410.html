개발자 업데이트 2025.4.10

2025년 4월 10일
인게임 프로필 수정 가능 및 지칭 대명사 기능 추가

스페이스 잼 2 우승자 발표 예정​

  • 4월 11일 수상자 발표
  • 4월 12일부터 5월 12일까지 공개

플레이어 설문 조사 참가 감사​

  • ur@vrchat.com 계정으로 설문조사를 발송하였고, 참가 해 주어서 감사

VRC+ 구독 뱃지​

  • 1개월 이상 구독자는 구독 기간 뱃지 받게 됨
  • 총 구독 기간을 의미하며, 구독이 활성화 되었을 경우에만 보임
  • 재구독하여도 기간은 저장되며, 직접 선물 합산하여 계산

인게임 프로필 수정 기능​

  • 인게임 내에서 프로필이 수정 가능
  • 지칭 대명사도 추가 가능하며, 네임플레이트 아래에 표시 가능

웹 사이트 수정​

  • 아바타 태그 수정 다일로그 업데이트를 위해 어쩔 수 없이 기존 태그 값들은 삭제됨

인스턴스 생성 설정 변경​

  • 인스턴스를 월드 제작자의 설정으로 만든 뒤, 필요할 때 인스턴스 설정을 변경하므로 인스턴스 설정 단계가 제거될 예정

VCC 업데이트 예정​

  • 패키지 업데이트 로그를 볼 수 있는 기능 추가
  • 전역 또는 프로젝트 별 Unity 실행 매개변수 설정 기능
