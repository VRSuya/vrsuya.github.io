# 개발자 업데이트 2024.8.8

## iOS 비공개 베타 출시 예정

- 비공개 베타 참여 여부와 상관 없이 VRCSDK로 iOS 컨텐츠 업로드 가능하게 할 예정
- VRChat에서 일부 유명 퍼플릭 아바타는 iOS로 직접 변환함
- 퀘스트 용으로 업로드된 컨텐츠는 iOS에서 쉐이더 교체를 통해 로드 시도
- 로드가 안 되는 컨텐츠는 리포트 요청

## 보안 업데이트

- 리핑 방지용으로 로컬 VRC 인스턴스에서는 본인이 업로드한 아바타, 퍼플릭 아바타만 로드 가능하게 변경
- 게임 캐시나 메모리 핵, API를 통해 아바타나 월드를 추출하고 변환한 도구를 사용한 약 2400개 계정을 추가 밴 처리
- 리핑을 위해 서브 계정을 통해 사용한 경우 본 계정도 밴 처리

## 웹에서도 친구 즐겨찾기 관리 가능

## 오프라인 상태인 친구를 초대하는 기능

- VRChat 모바일 앱을 통해 푸시 알림 받는 기능
- VRChat 웹사이트에 접속하고 있는 경우, 초대 가능
- 웹사이트나 모바일 앱에 접속 중인 경우 링 모양 아이콘으로 표시
- 얼마나 오랫 동안 오프라인인지 표시하는 기능 추가

## 카메라 기능 업데이트

- 세로 방향 카메라 모드 추가
- 초점 위치 보여주는 모드(제브라 패턴)
