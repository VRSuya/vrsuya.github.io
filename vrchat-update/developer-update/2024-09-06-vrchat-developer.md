# 개발자 업데이트 2024.9.5

![스티커](./20240905/93C9B3CA9CAD989D1280E66EC84AAB35A864E036.png)

## VRC+ 새로운 기능 : 스티커

- 월드에 스티커를 붙이는 기능 추가
- 개발 중인 현재 9개까지 보유 가능한 것으로 구현
- 스티커는 월드에 1인당 1개만 부착 가능
- 해당 스티커만 숨기는 기능, 인스턴스 퇴장 등 유저가 없어지면 스티커도 사라짐
- 월드에서 스티커 부착 허용 여부 설정 가능
- 스티커가 부적절하지 않은지 VRChat에서 검사함

![공유](./20240905/34B3A09513720472EE4D7941376DF9BBA5D16260.png)

## VRC+ 새로운 기능 : 공유

- 스티커나 이모지, UI 배색 등 컨텐츠 공유용 포탈 같은게 추가 예정
- 월드 포탈처럼 드랍이 되며, 일정 시간 또는 유저가 떠나기 전까지 드랍 가능
- 공유 가능한 대상 지정 가능(퍼블릭, 친구, 그룹 등)
- 이벤트 참가자용 선물처럼 다양한 이벤트나 모임에서 사용하기 좋을 듯
