# 개발자 업데이트 2024.10.3

## 할로윈 VRChat Jam 예정

- 10월 14일까지 제출
- https://hello.vrchat.com/blog/spookality-2024-arrives-october-1

## Udon 코드 서명

- 월드를 방문하면 플레이어 컴퓨터에 캐시 데이터가 생김
- 해당 캐시 데이터를 수정하여 월드의 제한 사항이나 결제 혜택을 우회하는 행위 발견
- 따라서 최신 VRCSDK에서는 Udon 코드에 서명하여 위조 방지할 예정
- 서명이 잘못되면 캐시를 폐기하고 새로운 월드 데이터를 받게 됨

## 뱃지 관리 기능

- 모두 보기, 숨기기, 3개까지 선택 가능

## 웹사이트 업데이트

- 링크를 첨부하면 디스코드나 트위터에서 미리보기 가능하게 변경

## 임포스터 업데이트

- 모자나 꼬리 등 좀 더 디테일하게 임포스터를 생성하도록 로직 보완

## 핸드트래킹 업데이트

- 빠른 메뉴 열기 방법에 손목에 아이콘을 넣거나 버튼을 누르면 열리게 추가함
- Expression 메뉴는 오른손 바닥을 하늘로 하고 엄지, 소지를 만나게 하면 열림
