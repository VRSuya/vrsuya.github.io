# 개발자 업데이트 2025.2.27

## 스페이스 잼(월드 경연) 개최

- 호주 국립 우주 협회(NSSA)가 주최하는 월드 경연
- 2월 24일부터 4월 5일까지 진행
- 수상자들에게는 호주 달러나 1년간 VRC+ 등 다양한 상품이 준비 되어 있어
- [자세한 내용](https://hello.vrchat.com/blog/space-jam-2025)

## InputField를 사용하는 월드 제작자 참고 사항

- 현재 InputField(입력 칸)를 비활성화를 하여도, VRChat 키보드 팝업으로 열 수 있는 버그가 있어
- Interactable(상호작용) 속성도 유사한 상태
- 향후 업데이트에서 해결하려고 하며, 이로 인한 피드백 받는 중

## 개발자 스트리밍 재개

- 매주 금요일 오후 2시(PST) [트위치 채널](https://www.twitch.tv/vrchat)에서 만날 수 있음

## VRChat 2024.1.2 릴리즈

- 메인 메뉴 UI, 연령 확인 업데이트 등
- [자세한 내용](https://docs.vrchat.com/docs/vrchat-202512)

## 웹 사이트에서 아바타 정보를 수정 가능

- 기본 아바타 정보
- 아바타 스타일 (인간형, 애니, 퍼리, 사물, 판타지 등등)
- 태그 10개 추가 (추후 아바타 마켓에서 검색 용도)
- 고지사항 (아바타에 어떤 에셋을 사용하였는지 표기 및 허가 여부)
- 갤러리(구매자들이 보고 참고할 사진 6장, FHD 해상도)

## 소바(Soba) 업데이트 진척사항

### 소바에 포함이 확인 된 내용

- 사용자 정의 추상(Abstract) 클래스, 인터페이스(Interface) 클래스, 정적(Static) 클래스
- 정적 필드
- UdonSharp 모든 기능

### 소바에 포함하려고 하는 내용

- 사용자 정의 클래스에 월드가 로드 될 때 실행되는 사용자 정의 생성자(정적 생성자 포함)
- 상속 트리 하위에서 사용자가 완전히 커스텀 할 수 있는 추상(Abstract), 가상(Virtual), 오버라이드(Override) 메소드와 프로퍼티
- 일반적인 C#과 같이 런타임에 실행되는 필드 초기화
- 메서드에 명명된 파라메터와 선택적인 파라메터 지원
- 재귀적인 메서드에는 RecursiveMethod 속성이 필요하지 않으며 성능 저하가 발생하지 않음
