# 개발자 업데이트 2025.5.22

## VRChat Pride 제출 시작

- 2025년 5월 28일(PST)에 Pride 기획의 일부 발표 예정
- 2025년 5월 30일 오후 12시(PST)에 마감
- [가이드라인](https://docs.google.com/presentation/d/1xT84ES2ouMHcSRN9TmCYc7Z5nYNnmd4wZ8DrFZKvZKE/edit#slide=id.p)
- [제출](https://docs.google.com/forms/d/e/1FAIpQLScyqVI-7VhY3SJEjVh_o1MO3TgUx3hz4d7d3eV5Tyd2tuIHSA/viewform)

## 여름 음악 페스티벌 컨테스트

- 6월 말에 다음 아바타 컨테스트 계획, 6월 16일 경에 발표 예정

## 아바타 마켓플레이스 발표

- VRChat 인게임 메뉴에서 아바타를 바로 찾고 구매할 수 있는 새로운 VRChat 플레이어를 위한 기능
- 아직 계속 개발 중이 기능이며 앞으로 어떻게 개발할지 계획을 가지고 있음
- 현재 1,000명 이상의 크리에이터가 아바타 마켓플레이스에 참여
- 참여를 원하면 [지원서](https://www.surveymonkey.com/r/GK8WNBN) 제출

## VRChat 2025.2.2 오픈 베타 릴리즈

- VRChat 아바타 마켓플레이스 포함
- 월드 다운로드 및 서버 프로세싱(아바타)이 빨라짐
- [패치 노트](https://docs.vrchat.com/docs/vrchat-202522-openbeta)

## 웹 업데이트

- 마켓플레이스 관리 페이지 문제 수정
- 웹에서 아바타 신고 기능 추가
- 마켓플레이스에서 삭제 되거나 비활성화된 컨텐츠 핸들링 개선
- 다양한 가이드 및 지원 URL 수정
- 아바타가 잘못된 URL로 공유 되는 문제 해결
- 마켓플레이스 마감 알림 개선
- UI 스위치 색상 대비 개선
