# VRChat 2024.1.2

- 압축 되지 않은 크기를 볼 수 있는 UI와 크기 제한을 설정할 수 있는 기능 추가됨
- 로딩 스크린, 툴팁과 색상 팔레트가 변경됨
- 커스텀 이모지 제한이 5에서 9로 증가 (VRC+ 구독자)
- 인스턴스 주인장인 경우 사람이 추가로 더 못 들어오게 하는 기능 추가
- VRCHeadChop 컴포넌트 추가(Head 본 아래 보이고 싶은 요소(귀나 머리카락)를 보이게 설정 가능)
- AnimatorPlayAudio 컴포넌트 추가(애니메이션 State에서 여러 오디오 재생 기능)
- Fallback 쉐이더로 아바타 모습을 디버그 하는 기능 추가됨
